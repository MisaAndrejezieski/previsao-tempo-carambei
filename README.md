# Previsão do Tempo - Carambeí

Aplicativo desktop com interface gráfica para consultar a previsão do tempo em Carambeí (PR) utilizando a API do wttr.in.

## Funcionalidades
- 🌤️ Consulta rápida do clima atual
- 📊 Detalhes completos da previsão
- 📅 Previsão para os próximos dias
- Interface amigável com Tkinter

## Como usar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute: `python previsao_tempo.py`

## Tecnologias
- Python 3
- Tkinter (GUI)
- Requests (API)
